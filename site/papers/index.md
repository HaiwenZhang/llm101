# 论文学习库

<div class="lesson-lead">这里不是让你一次读完 33 篇。现在每篇都有独立中文学习页：先用类比建立直觉，再拆核心机制、实验依据、与 K3 的关系、适用边界和原文章节地图。</div>

## 怎么使用这 33 页

1. 点标题进入学习页，不要直接硬啃 PDF；
2. 先读“为什么出现”和“核心机制”，闭卷讲一次；
3. 再看“论文拿什么证明”，区分实验事实与解释；
4. 最后按推荐页码打开原文，只精读相关章节。
